# Interface assets

`discord.svg` is the official Discord symbol from https://discord.com/branding
(downloaded 2026-11-14). Discord retains its trademark rights. Used to identify
the Discord integration; no affiliation or endorsement is implied.

Other interface symbols use [Lucide](https://github.com/lucide-icons/lucide),
downloaded 2026-11-18. Original SVG files are bundled locally, with no runtime dependency.
All share a 24 px grid, 2 px strokes and rounded caps/joins. GPUI supplies the
monochrome color for normal, active and disabled states.

Mapping: `console.svg` = `gamepad-2`, `audio.svg` = `volume-2`; `image`, `settings`,
`check` and `chevron-down` retain their upstream names.

See `LUCIDE-LICENSE` for the ISC notice and the MIT notice covering Feather-derived
icons. The same notices are included in the application's `THIRD_PARTY_LICENSES.txt`.
