# Перенос Console Link на GPUI

Основной бинарник использует GPUI 0.2.2. Вариант egui оставлен только под feature `legacy-ui` для отката; в стандартную сборку eframe не входит. Исходный CPU-прототип остается в experiments/gpui-preview как отдельный опыт.

## Состав

- src/gpui: пять экранов, IME/Unicode ввод, выбор устройств, аудиомикшер/EQ, изображение/пресеты, Discord/Nintendo, настройки и мониторинг.
- src/runtime: подключение и восстановление, FrameHistory/синхронизация, аудио, авторизация и presence, определение игры Nintendo и установка компонентов, настройки, PNG. Runtime не зависит от UI.
- src/gpu: общие постоянные color/NIS/FSR/RTX passes. Старый frontend использует те же алгоритмы через тонкие egui callbacks. Шейдеры и эталонные данные не менялись.

## Видеовывод

Capture -> ограниченная очередь -> runtime/history -> wgpu GPU passes -> native surface. GPUI рисует элементы поверх второй GPU-поверхностью в том же OS window.

На Mac native NSView располагается ниже прозрачного GPUI view. На Windows child HWND использует DX12; GPUI DirectComposition вызывает CreateTargetForHwnd(hwnd,true), поэтому UI компонуется поверх child window. Обмен текстурами между D3D11/D3D12 не нужен. При отключенном DirectComposition возвращается явная ошибка. CPU readback используется только по запросу скриншота, не для воспроизведения. Исходный BGRA/RGBA CPU capture conversion сохранен; полный zero-copy HDMI не заявляется.

Surface уничтожается раньше view/HWND. Windows WM_DESTROY очищает общий surface slot; close/quit дополнительно вызывают shutdown. Закрытие игры возвращает главное меню; закрытие главного меню завершает приложение. Cmd+Q/Ctrl+Q завершают приложение явно.

## Совместимость

Настройки, schema, Keychain/Credential Vault, Discord Application ID и пути данных Nintendo прежние. Изолированный режим --synthetic/--smoke-seconds не открывает пользовательские настройки, аккаунты, камеру и сеть. Скриншоты используют неизменяемый рецепт фактически показанного кадра, включая сравнение и Standard fallback. До первого настоящего кадра и после остановки экспорт запрещен.

Все режимы окна переключаются во время игры. F11 возвращает предыдущий режим, F10 циклически меняет три режима. Оконная геометрия сохраняется. Курсор скрывается через четыре секунды только внутри активного игрового окна и восстанавливается при движении, выходе из окна, оверлее и завершении.

## Проверки

Локально: строгий Clippy для стандартных targets прошел; 122 теста библиотеки и 10 тестов GPUI прошли. Пять проверок hardware/benchmark/live Nintendo остаются ignored. Общие GPU-тесты проверили цвет, NIS/FSR, повторное использование ресурсов, эталонные изображения и PNG; добавлена регрессия неподдерживаемого NIS с сохранением видео и effective export.

Независимая проверка закрыла ошибки fallback, comparison, возврата окна после disconnect, F11 return mode и экспорта calibration/устаревшего кадра. Финальные native smoke и CI фиксируются в PR. Успешная синтетика не доказывает реальную HDMI-задержку, поддержку конкретной USB-карты, RTX или работу демонстрации Discord/OBS.

Основные источники: https://gpui.rs/, точный опубликованный gpui 0.2.2 и документация Microsoft IDCompositionDevice::CreateTargetForHwnd. Изменений GPUI upstream или собственного fork нет.

## Дизайн

Навигация в стиле Discord; цветовая схема темная, ближе к Codex, только ахроматические темные, белые и серые оттенки. На главной видеозона занимает все свободное место, подключение расположено в правой панели. В навигации и игровом оверлее используется новый минималистичный логотип с геймпадом. Разрешение выбирается из уникальных размеров без FPS; отдельный выбор FPS пересчитывает поддерживаемый режим, сохраняя выбранное разрешение и исходную дробную частоту.
