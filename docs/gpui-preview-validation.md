# GPUI Preview: проверка первого прототипа

Дата: 13 ноября 2026. Это отдельный экспериментальный frontend, не новая версия установленного Console Link.

## Mac: выполненные проверки

- `gpui =0.2.2` с `runtime_shaders` собран на Apple Silicon с Command Line Tools, без `xcrun metal`.
- Отдельный `.app` с собственным bundle ID прошел `plutil -lint` и `codesign --verify --deep --strict`. Подпись ad-hoc, не notarization.
- Два запуска синтетического Full HD с автоматическим выходом через 20 и 90 секунд завершились с кодом 0.
- После прогрева короткого запуска вход и обновления UI составляли около 60 кадров/с. CPU-подготовка последнего кадра занимала примерно 3,3-4,7 мс. Это не GPU upload, не display FPS и не задержка от HDMI до экрана.
- В длинном запуске были значительные провалы обновлений UI при продолжающемся источнике. Итог: 5325 полученных кадров, 4387 обновлений UI, 938 замен устаревшего кадра в очереди. Причина пауз не установлена. Стабильные 60 FPS на этом основании не заявляются.
- Счетчик освобождения atlas: 4386 при 4387 обновлениях. Предыдущее изображение удаляется явно; текущее остается во view.
- Одна выборка `ps` во время длинного запуска показала RSS 142496 КиБ и CPU 44,1%. Это одна точка, не доказательство стабильности памяти или преимущества перед egui.

Снять окно через `screencapture -l` не удалось. Визуальная приемка, обработка реальных клавиш, DPI и переключение фокуса пока не подтверждены автоматической проверкой. В отдельном финальном прогоне обычное окно и нативный fullscreen завершились с кодом 0; telemetry подтвердила переход fullscreen=true. В безрамочном старте обнаружено и исправлено смещение вниз на 33 пункта: GPUI 0.2.2 сохраняет NSTitled даже при titlebar=None. Узкий AppKit helper задает настоящий Borderless и frame текущего NSScreen. Повторный запуск подтвердил origin=(0,0), bounds/viewport=1728x1117, scale=2, fullscreen=false. Безрамочное окно не создает отдельный native fullscreen Space. Переход из этого режима в native fullscreen в прототипе явно отключен; обычный оконный/fullscreen путь сохранен.

Автоматический выход перенесен из render() в отдельный GPUI timer. Финальная безрамочная проверка --smoke-seconds 5 завершилась с кодом 0 за 5,44 секунды от старта процесса. На deadline геометрия осталась (0,0,1728,1117), fullscreen=false; 311 полученных кадров, 305 обновлений UI, 6 замен в очереди.

Финальные локальные проверки вложенного crate: сборка, строгий Clippy для всех targets и 3 теста прошли. Основной Cargo.toml/Cargo.lock и рабочий frontend не изменены.

## Что не подтверждено этим опытом

- Реальный захват через новое разрешение камеры GPUI Preview.
- Звук, Discord, Nintendo, скрытие курсора и остальные экраны нового frontend.
- Сохранение нынешних цветовых/NIS/FSR/RTX GPU-проходов.
- Отсутствие лишних копий кадра и сравнение задержки с прежним frontend.
- Длительная стабильность GPU-памяти и Windows 11 runtime-поведение.

Результаты компиляции Windows и автоматических проверок фиксируются отдельно в GitHub Actions. Успешная сборка не заменяет проверку окна на настоящей Windows 11.
