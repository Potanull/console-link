# Установка компонентов Nintendo

В разделе Discord включи получение игры из Nintendo и нажми «Установить компоненты Nintendo». Приложение загрузит отдельный Node.js и закрепленный nxapi. Системные Node/npm, PATH и пользовательский npm-конфиг не меняются. Для установки нужен доступ к nodejs.org и registry.npmjs.org.

После установки кнопка меняется на «Проверить/восстановить компоненты». Она сначала проверяет имеющиеся компоненты; при неисправности повторяет установку. Новая рабочая версия активируется после проверки. Ошибка загрузки или проверки не заменяет предыдущие файлы.

## Установка и вход - разные действия

Установщик не входит в Nintendo и не создает аккаунты. Для автоматического статуса по-прежнему нужен настроенный вход второго аккаунта nxapi и выбор основного профиля среди его друзей. Существующий каталог входа сохраняется, даже если прежняя установка nxapi повреждена или удалена.

Компоненты находятся в пользовательском каталоге `ConsoleLink/nintendo-helper/runtimes/v1`. Данные входа находятся отдельно в `data`; прежний настроенный development-каталог также поддерживается. Установщик работает только внутри `runtimes`, не копирует и не удаляет данные аккаунтов.

## Закрепленные версии

- Node.js `v24.22.3`: официальный архив для Mac Apple Silicon или Windows x64. SHA256 встроен в приложение и проверяется перед распаковкой.
- nxapi `1.6.1-next.257`: точная версия в `packaging/nintendo/package.json`.
- Все транзитивные пакеты закреплены в `package-lock.json` с HTTPS-адресами npm и SHA512. Обновления компонентов приходят с изменениями Console Link, а не через `npm install latest`.
- Optional `register-scheme` закреплен через npm override, чтобы установка не требовала Git или SSH.

Используется приватный npm из загруженного Node: `npm ci --omit=dev --ignore-scripts`. Пользовательские npm-конфиги и окружение с токенами не передаются. Логи npm отключены. Распаковка использует штатный `tar` macOS/Windows 11, без shell-команд с подставляемыми путями.

Компоненты загружаются напрямую с исходных сайтов и не включены в дистрибутив Console Link. Сохраняются лицензии установленных пакетов: Node.js MIT и лицензии его компонентов, nxapi AGPL-3.0-or-later. См. также [состав runtime](../packaging/nintendo/README.md).

## Проверка и восстановление

Установка выполняется в отдельном рабочем потоке. Межпроцессная блокировка защищает временный каталог. После загрузки проверяются контрольная сумма, версия приватного Node, версия пакета nxapi и запуск `nso friends --help` с отдельным пустым каталогом данных. Пробный запуск не использует настоящий аккаунт и не запрашивает его друзей.

Установщик задает приватное окружение и рабочий каталог. Дочерние процессы имеют ограниченное время работы; закрытие приложения отменяет установку и завершает принадлежащий ей процесс. Незавершенный временный каталог очищается при следующей попытке под блокировкой.

Для изолированной проверки, в том числе в CI, используется тот же установщик:

```sh
cargo run --locked -- --install-nintendo-runtime /absolute/temporary/directory
```

Путь должен быть абсолютным. Для проверки не следует указывать настоящий каталог входа. В workflow есть режим `nintendo_components_only`: проверка установки на Mac/Windows без GPU-тестов и публикации приложения.

## Граница гарантии

Эта схема устраняет зависимость от системного Node и ручной установки npm-пакетов. Она не гарантирует неизменность неофициального Nintendo API: изменения сервиса могут потребовать новой версии nxapi или Console Link.
