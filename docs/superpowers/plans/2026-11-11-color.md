# Color Correction Implementation Plan

> **For agentic workers:** Use bounded parallel agents for independent GPU/UI files; root owns core/settings/integration and verifies all outputs.

**Goal:** Deliver approved SDR grading/HDR-like presets without adding CPU playback transforms.
**Architecture:** Pure CPU reference math and screenshot export; same math in a persistent single-pass wgpu video callback; existing global serde settings/preset pattern and egui pages.
**Tech Stack:** Rust2024, egui/eframe0.33.3, wgpu27, existing serde/png; no new runtime dependencies.
**Spec:** ../specs/2026-11-11-color-design.md

## Global constraints
- Preserve user's existing uncommitted refactor and all audio/Discord/playback behavior.
- No true HDR claims, new frame queues, automatic game recognition or CPU grading in playback.
- Original toggle transient; presets/settings persist; old schema1 remains readable.
- Keep current one-row EQ and bounded overlay.

## Review focus
- CPU/GPU sRGB transfer, alpha, uniforms layout and output target format match.
- Bypass matches original without normalization round-trip.
- GPU textures recreated only on dimension change and uploaded once per frame; callback source lifetime valid.
- Per-click screenshot settings stable while sliders continue changing.
- Preset CRUD can't overwrite factory definitions; invalid persisted values remain bounded.
