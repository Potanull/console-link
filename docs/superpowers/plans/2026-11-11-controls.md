**Architecture:** Existing egui UI, CPAL output callback DSP, serde settings, manual game catalog.
**Tech Stack:** Rust 2024, egui 0.33, CPAL 0.16.
**Spec:** ../specs/2026-11-11-controls-design.md

## Global Constraints
- Preserve existing uncommitted module refactor and Windows/macOS behavior.
- No new codec or DSP runtime dependencies; no automatic commits.
- Keep schema 1 readable and user screenshot actions available.

## Review Focus
- Legacy settings must load without resetting user preferences.
- Invalid EQ values must never reach the callback.
- Bypass and mute must produce exact original/silent output.
- Presets survive serialization; factory defaults cannot be overwritten.
- No OCR frame submission or Discord launch action may remain.
