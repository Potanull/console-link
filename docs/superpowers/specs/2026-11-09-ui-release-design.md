# Console Link 0.2.0: интерфейс и поставка

Основание: пользователь поручил профессионально переработать UI, опубликовать GitHub Release с готовыми файлами и добавить Windows-установщик.

## Интерфейс

Сохраняем egui/wgpu и все существующие функции. Предложение автора: темный монохромный стиль в духе уже выбранной черно-белой иконки. Четкая типографика, карточки, заметная основная кнопка, достаточные отступы. Основной сценарий подключения виден сразу; подробности Discord и диагностика не конкурируют с ним. Крупное окно адаптируется к меньшей ширине. Игровое окно остается чистым.

Рассмотрены локальная переработка egui и замена UI-фреймворка. Выбрана первая: позволяет улучшить композицию и виджеты, сохранив проверенный media lifecycle и компактную поставку. Замена фреймворка без потребности в новых возможностях не оправдана.

Состояния подключения, ошибки, невыбранные устройства, reconnect и disabled controls оформляются как реальные состояния, а не декоративные показатели. Громкость/mute, sync offset, скриншоты, ручная игра Discord, выбор входа/выхода и сохранение настроек сохраняются.

## Установщик и релиз

Windows x64: установщик для текущего пользователя, без обязательного elevation, запись в LocalAppData/Programs, ярлык в меню Пуск, необязательный ярлык на рабочем столе, штатное удаление. Постоянный AppId обеспечивает последующие обновления. Исполняемый файл, иконка и лицензионные уведомления входят в комплект.

GitHub Release публикует Mac arm64 .app ZIP, Windows setup .exe, Windows portable ZIP и SHA256SUMS. Релиз создается вручную запускаемым workflow после нативных проверок и проверки Windows install/uninstall в одноразовом каталоге CI. Публикация разрешена поручением пользователя. Токен остается в стандартном окружении GitHub Actions; права contents:write получает только publish job.

Первый релиз помечается предварительным: аппаратная приемка карты и реальный Discord-звонок еще не завершены. Локальная Mac-сборка проверяется реальным запуском; сам UI проверяется по снимку собственного renderer. Полное описание медиаограничений остается в docs/validation.md.

## Критерии готовности

- Визуально проверенный новый интерфейс, без потери существующих controls.
- Тесты, Clippy, форматирование и нативные сборки обеих ОС проходят.
- Windows setup устанавливает и удаляет приложение в CI без запуска GUI.
- GitHub Release существует, assets и checksums доступны для скачивания.
- Версия 0.2.0, версия bundle и Windows metadata согласованы.
