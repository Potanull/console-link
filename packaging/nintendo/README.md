# Управляемый Nintendo runtime

Манифест и lockfile используются для установки компонентов по кнопке в Console Link. Глобальная установка Node.js или npm-пакетов не нужна. В сборку приложения входят эти файлы и метаданные загрузки, а не бинарные файлы nxapi.

Закреплены Node.js `v24.22.3`, nxapi `1.6.1-next.257` и все транзитивные зависимости из `package-lock.json`. Для необязательной зависимости discord-rpc закреплен `register-scheme@0.0.2` из npm registry вместо GitHub/SSH. Его native install script не выполняется; установка не требует git или SSH-доступа. Lockfile содержит необязательные платформенные пакеты sharp; npm выбирает подходящие для текущей системы.

Приложение скачивает официальный архив Node.js, сверяет встроенный SHA256 и сохраняет приватный runtime. Затем его npm выполняет `ci --ignore-scripts --omit=dev --no-audit --no-fund` с этим lockfile. Lifecycle scripts зависимостей отключены. После установки проверяется только версия nxapi, без входа в аккаунт или запросов Nintendo.

## Источники и лицензии

- Node.js: [официальные архивы](https://nodejs.org/dist/v24.22.3/) и [контрольные суммы](https://nodejs.org/dist/v24.22.3/SHASUMS256.txt). Node.js распространяется по MIT; официальный архив также содержит уведомления и лицензии включенных компонентов в `LICENSE`. Этот файл следует сохранять вместе с runtime.
- nxapi: [пакет npm](https://www.npmjs.com/package/nxapi/v/1.6.1-next.257), лицензия `AGPL-3.0-or-later`. npm скачивает пакет напрямую при установке пользователя. Установка сохраняет лицензии пакетов; приложение не включает авторизацию, пользовательские данные или копию nxapi в свой дистрибутив.
- sharp: `Apache-2.0`; платформенные зависимости могут иметь другие лицензии, включая лицензии libvips. Их уведомления находятся в скачанных пакетах. Lockfile закрепляет версии, URL и integrity всех пакетов.

Для обновления зависимостей нужно заново проверить официальные SHA256, версии и структуру архивов, затем обновить `src/nintendo/runtime_config.rs`, манифест и lockfile вместе. Lockfile генерируется через публичный npm registry с пустыми пользовательским и глобальным npm-конфигами, без lifecycle scripts.
