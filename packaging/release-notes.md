## Console Link

Специализированное приложение для подключения HDMI-консоли через карту захвата к Mac или Windows 11.

В этой версии:

- Динамическое локальное OCR-распознавание названия по кадру и общему каталогу 24 017 игр Switch. Два уверенных наблюдения обновляют игру; есть выключатель и ручная коррекция. Это не пользовательские пресеты.
- Discord Presence с названием конкретной игры, обложкой и таймером. Ответ Discord проверяется: игнорирование названия показывается отдельно.
- Карточка подключенного аккаунта с аватаром, предпросмотр игры и состояние распознавания.
- Возврат в приложение после OAuth через native focus и tokenless `console-link://`, зарегистрированный установщиком Windows и Mac .app. Браузер может потребовать подтверждение открытия приложения.
- Подсказка демонстрации при запуске игры и кнопка перехода в Discord. Сам показ запускается пользователем: публичного API для принудительного Go Live popup нет.

Первый анализ загружает около 12 МБ OCR-моделей. Анализ локальный, кадры в сеть не отправляются. Нужен читаемый полный текст названия на титульном экране/HOME/меню. Модели распознают латиницу; произвольный геймплей и сложные логотипы не гарантируют определения. Последнее подтвержденное название сохраняется во время игры. Совместимость реальной карты, вход/возврат и отображение карточки в живом Discord требуют аппаратной проверки.

Сохранены Full HD по умолчанию, 60 FPS при поддержке карты, безрамочный полный экран, оверлей F1, горячие клавиши и скриншоты исходного кадра.

### Что скачать

- **Windows 11 x64:** файл `Console-Link-…-Setup-x64.exe`. Архив `…-windows-x64.zip` - переносимая версия без установки.
- **Mac с Apple Silicon, macOS 13+:** архив `…-macos-arm64.zip`. Распакуйте и откройте `Console Link.app`.
- `SHA256SUMS.txt` содержит контрольные суммы файлов.

### Статус проверки

Это предварительный выпуск для аппаратной проверки. Перед публикацией CI проверяет обе платформы, создает пакеты и выполняет установку/удаление Windows-пакета в тестовой директории. Совместимость конкретной карты, задержка и звук на принимающей стороне Discord требуют отдельного аппаратного прогона.

Windows-файлы пока без code signing, Mac-пакет имеет ad-hoc подпись без Apple notarization. Необходимость разрешений камеры/аудиовхода определяется ОС; права администратора для штатной установки Windows не требуются.
