## Console Link

Специализированное приложение для подключения HDMI-консоли через карту захвата к Mac или Windows 11.

В этой версии:

- Компактный индикатор текущей громкости с полоской появляется на 2 секунды при регулировке и mute, включая горячие клавиши.
- Во время игры курсор скрывается после 4 секунд без движения. Движение мыши, открытие панели или возврат фокуса возвращают его. В обычном меню курсор не скрывается.
- Автоматический режим предпочитает Full HD (1920 × 1080), затем ближайший доступный к выбранному лимиту FPS. Например, при цели 60 FPS карта с режимами 1080p30/720p60 выбирает 1080p30. Если Full HD нет, используется реальный доступный режим; ручной выбор сохранен.

Сохраняются игровой оверлей F1, три режима окна, горячие клавиши и предварительная интеграция Discord. Реальный вход Discord и аппаратный захват пока требуют проверки владельцем. Автораспознавание игры пока не включено. Индикатор и открытая панель видны в захвате окна Discord/OBS, скриншоты содержат только исходный кадр.

### Что скачать

- **Windows 11 x64:** файл `Console-Link-…-Setup-x64.exe`. Архив `…-windows-x64.zip` - переносимая версия без установки.
- **Mac с Apple Silicon, macOS 13+:** архив `…-macos-arm64.zip`. Распакуйте и откройте `Console Link.app`.
- `SHA256SUMS.txt` содержит контрольные суммы файлов.

### Статус проверки

Это предварительный выпуск для аппаратной проверки. Перед публикацией CI проверяет обе платформы, создает пакеты и выполняет установку/удаление Windows-пакета в тестовой директории. Совместимость конкретной карты, задержка и звук на принимающей стороне Discord требуют отдельного аппаратного прогона.

Windows-файлы пока без code signing, Mac-пакет имеет ad-hoc подпись без Apple notarization. Необходимость разрешений камеры/аудиовхода определяется ОС; права администратора для штатной установки Windows не требуются.
