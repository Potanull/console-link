## Console Link

Специализированное приложение для подключения HDMI-консоли через карту захвата к Mac или Windows 11.

В этой версии:

- Автоматический выбор режима карты с целью 60 FPS и настройками частоты/ручного режима. Неподдерживаемые кадры не дорисовываются.
- Во время игры меню сменяется изображением консоли. F1 открывает правую панель поверх игры; остановка и закрытие игрового окна возвращают меню.
- Оконный режим, окно без рамок, полный экран. F11/Alt+Enter/Cmd+Enter - fullscreen, F10 - смена режима, F8 - скриншот, M - mute, +/- - громкость, Ctrl/Cmd+Shift+Enter - остановка.
- Подключение аккаунта Discord через браузер с PKCE и защищенным хранением refresh token. Статус передается только при совпадении аккаунта с настольным Discord. Название игры задается вручную, показ можно отключить.
- Исправлены потери FPS при ровном потоке 60 Гц, частые перерисовки без новых кадров и восстановление Discord после временных сетевых ошибок.

Реальный браузерный вход Discord и его системное хранилище пока не проверены владельцем. Эта интеграция предварительная. Автораспознавание игры не включено: для следующей версии предложен локальный OCR с подтверждением пользователя. Панель поверх игры видна в захвате окна Discord/OBS, скриншоты содержат только исходный кадр.

### Что скачать

- **Windows 11 x64:** файл `Console-Link-…-Setup-x64.exe`. Архив `…-windows-x64.zip` - переносимая версия без установки.
- **Mac с Apple Silicon, macOS 13+:** архив `…-macos-arm64.zip`. Распакуйте и откройте `Console Link.app`.
- `SHA256SUMS.txt` содержит контрольные суммы файлов.

### Статус проверки

Это предварительный выпуск для аппаратной проверки. Перед публикацией CI проверяет обе платформы, создает пакеты и выполняет установку/удаление Windows-пакета в тестовой директории. Совместимость конкретной карты, задержка и звук на принимающей стороне Discord требуют отдельного аппаратного прогона.

Windows-файлы пока без code signing, Mac-пакет имеет ad-hoc подпись без Apple notarization. Необходимость разрешений камеры/аудиовхода определяется ОС; права администратора для штатной установки Windows не требуются.
