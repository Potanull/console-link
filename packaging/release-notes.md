## Console Link 0.6.1

Исправление подключения карт захвата на macOS.

### Исправления

- Убрана ошибочная обязательная проверка пресета InputPriority, предназначенного для iOS/Catalyst. На macOS задаются объявленные устройством activeFormat и длительности кадров. После запуска проверяется размер кадра. Служебные длительности UVC-драйвера больше не блокируют рабочий поток; фактический FPS измеряется по полученным кадрам.
- Апскейлеры NIS/FSR больше не компилируются при обычном запуске. При ошибке GPU приложение сохраняет обычное масштабирование и показывает причину; RTX Video недоступен для выбора на Mac.
- Ошибка подключения показывается над карточками устройств, без прокрутки. После отказа нижняя панель больше не пишет, что все готово.
- Добавлен необязательный ограниченный журнал этапов подключения. Он не содержит кадров, звуковых сэмплов, настроек, токенов или идентификаторов устройств. Без явного диагностического параметра файл не создается.

Сохранены функции 0.6.0: NIS/FSR 1, необязательная RTX Video интеграция Windows и получение активности Nintendo через отдельно настроенный локальный nxapi.

### Что скачать

- Windows 11 x64: `Console-Link-0.6.1-Setup-x64.exe`; portable `console-link-0.6.1-windows-x64.zip`.
- Mac Apple Silicon, macOS 13+: `console-link-0.6.1-macos-arm64.zip`.
- `SHA256SUMS.txt`: контрольные суммы.

### Статус

Сбой воспроизведен на реальной USB3 .0 Video: версия 0.6.0 отказывала до запуска видео из-за InputPriority. Проверочная сборка получила и отобразила Full HD кадр; запуск USB3.0 Audio на выбранный монитор проверен с mute. Это не подтверждает слышимость звука, содержимое HDMI, задержку или Discord-звонок.

Windows-файлы без code signing. Mac-пакет имеет ad-hoc подпись без Apple notarization, поэтому для скачанного приложения может понадобиться разрешение Open Anyway в настройках macOS. Пользовательские настройки сохраняются.
